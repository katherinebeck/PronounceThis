#   - flap T / D (water, better, letter)
#   - schwa (about, another)
#   - short-A / broad-A (aunt, dance)
#   - either / neither, route, roof, been, been
# Plus common auditioning vocabulary (character names, cities, months).
# Each line is one word or phrase — blanks and #-comments are ignored.
